1. Apresentação

A presente Política de Privacidade tem como objetivo informar como o INCLUCITY coleta, utiliza, armazena e protege os dados pessoais de seus usuário. Ao utiliza a plataforma, o usuário declara estar ciente das práticas descritas neste documento.

2. Dados Coletados

O IncluCity pode coletar os seguintes dados:
2.1 Dados fornecidos pelo usuário:

  • Nome
  • E-mail
  • Informações inseridas em avaliações e comentários

2.2 Dados coletados automaticamente:

  • Endereço IP
  • Informações do dispositivo
  • Dados de navegação

3. Finalidade do uso dos dados

Os dados coletados são utilizados para:

  • Permitir o funcionamento da plataforma
  • Melhorar a experiência do usuário
  • Exibir conteúdos personalizados
  • Garantir segurança e prevenção de fraudes
  • Gerar estatísticas de uso

4. Compatilhamento de dados

O IncluCity não compartilha dados pessoais com terceiros, exceto:

  • Quando exigido por lei
  • Para cumprimento de obrigações legais
  • Para proteção dos direitos da plataforma

5. Armazenamento e Segurança

Os dados são armazenados em ambiente seguro e protegidos contra acesso não autorizado, uso indevido ou divulgação.
